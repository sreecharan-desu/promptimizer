The console is the product surface at `/console`.

<Steps>
  <Step title="Connect">
    Simulator, or a provider chip + key. Base URL only for Custom.
  </Step>
  <Step title="Fleet">
    Every chat model with a tier dropdown. Set the baseline (always-expensive) model.
  </Step>
  <Step title="Playground">
    One prompt. The side rail shows model, tier, complexity, cache, quality gate, saved %.
  </Step>
  <Step title="Benchmark">
    The 15-row table. Gold savings with a near-zero quality delta.
  </Step>
</Steps>

<Note>
  Theme toggle lives in the footer: dark → light → system. Gold marks savings on both canvases.
</Note>
